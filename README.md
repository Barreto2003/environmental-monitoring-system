# Environmental Monitoring System

Distributed environmental monitoring system developed in Java for the Distributed Systems course at the University of Évora.

The system collects, stores, and monitors temperature and humidity data using REST, gRPC, and MQTT communication protocols.

Collected data is persisted in a PostgreSQL database and exposed through REST endpoints for querying environmental metrics by room, department, floor, and building.

## Technologies

- Java
- Spring Boot
- PostgreSQL
- JPA/Hibernate
- REST
- gRPC
- MQTT
