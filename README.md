# Environmental Monitoring System

Distributed environmental monitoring system developed in Java for the Distributed Systems course at the University of Évora.

The system monitors temperature and humidity across university spaces using multiple communication protocols, including REST, gRPC and MQTT.

## Features
- Spring Boot backend server
- REST API for device management
- MQTT sensor data ingestion
- gRPC data ingestion
- PostgreSQL database persistence
- Admin CLI client
- Synthetic IoT sensor simulators

## Technologies
- Java
- Spring Boot
- PostgreSQL
- JPA/Hibernate
- REST API
- gRPC
- Protocol Buffers
- MQTT
- Maven
